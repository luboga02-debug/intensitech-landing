# IntensiTech Solutions — Landing Page Oficial

Plataforma web institucional e montra de software clínico para a **IntensiTech Solutions, Sociedade Unipessoal Lda.** (Luanda, Angola).

---

## 🚀 Sobre o Projeto

Landing page de alta conversão desenvolvida sob a filosofia de design **Consulting Premium**:
- **Design System:** Estética clínica sóbria com paleta primária Dark Navy (`#122B3A`), Secondary Navy (`#1E4D6B`) e destaque tecnológico em Ciano (`#00A8CC`).
- **Mobile-First:** Otimizada para médicos e profissionais de saúde em ambiente de emergência e UCI que acedem a partir do telemóvel.
- **Portfólio de Aplicações:**
  1. **Vasoactivos** *(Produto Estrela)*: Calculadora avançada e titulação contínua de aminas/inotrópicos.
  2. **StrokeGuide Pro**: Apoio à decisão no AVC agudo e janelas de trombólise.
  3. **MalariaGrave Angola**: Protocolo clínico e posologia de artesunato IV.
  4. **IntensiScore & Ventilação**: Mecânica ventilatória e registo diário de escores (SOFA, APACHE II).
- **Conformidade Legal:** Secção de aviso médico obrigatório (*Medical Disclaimer*), Política de Privacidade e Termos de Uso em conformidade com o Google Play Console e Apple App Store.

## 🌐 Como Fazer o Deploy no Vercel

### Opção 1: Via Conexão com GitHub (Recomendado)
1. Crie um repositório no seu GitHub chamado `intensitech-landing`.
2. Faça o upload ou `git push` destes ficheiros para a branch principal (`main`).
3. Aceda a [vercel.com](https://vercel.com) e inicie sessão com o GitHub.
4. Clique em **Add New...** > **Project** e importe o repositório `intensitech-landing`.
5. O Vercel deteta automaticamente como site estático. Clique em **Deploy**.

### Opção 2: Conectar Domínio Próprio no Vercel
1. No painel do projeto no Vercel, vá a **Settings** > **Domains**.
2. Adicione o seu domínio (ex: `intensitechsolutions.com` ou `intensitech.co.ao`).
3. Configure os registos DNS apontando o `CNAME` ou registo `A` conforme indicado pelo Vercel.
